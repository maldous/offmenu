Find your account and back up your kitchen

Open Profile & backup in the kitchen. Opening the panel does not make a backup.

Under Backups & recipe imports, choose Export kitchen backup to download a file. Keep it private. Before restoring, export your current kitchen: restoring can replace its contents. The separate Download encrypted account backup needs an eligible signed-in account and configured backup. If it’s unavailable, don’t assume there’s a cloud copy.

Invalid pantry backup. That file was not restored. For Restore backup, choose a file made with Export kitchen backup. To add recipes from a recipe JSON file, use Import recipes (offmenu JSON) instead.

Recover from a recipe import error

In Profile & backup → Backups & recipe imports, choose Import recipes (offmenu JSON). Use an OffMenu recipe JSON file, not a pantry backup, PDF or shopping CSV.

  • Choose a valid JSON file and try again. Pick a valid OffMenu recipe JSON file.
  • File must be under 2 MB. Choose a file no larger than 2,000,000 bytes.
  • Import stopped: recipes with a matching ID contain different details. Existing recipes were kept. Check the differing recipes before retrying. Import does not overwrite an existing recipe with a different version.

Reading this guide does not retry the import. For pantry files, use Kitchen backup help.
