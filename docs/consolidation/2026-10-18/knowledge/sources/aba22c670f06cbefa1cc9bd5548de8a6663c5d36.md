## Contract and owner-controlled adoption

`evaluateAssertionDependencies(assertions, {clock, permit, withdrawn})` returns
one `{ref, allowed, reason, blockedBy}` decision per input, without copying values
or modifying inputs. Every node represents one field assertion. References
require explicit nonempty strings for `owner`, `sourceId`, `id`, `predicate`,
and `version`. Each dependency resolves that entire tuple; a replacement version
never silently substitutes. Known independent roots require `dependencies: []`.
Do not convert absent provenance to an empty dependency list.

Injected `clock` returns finite milliseconds. Injected synchronous `permit`
must return `{allowed: true}` only after the existing current rights policy has
admitted that specific field, account, action, audience, market, entitlement,
consent, attribution and rights revision. No policies or rights are invented by
this module. A caller adapter can reuse `admission` like this, after its other
required rights/revision gates:

```js
const decisions = evaluateAssertionDependencies(authorizedFieldSnapshot, {
  clock: () => requestNow,
  withdrawn: exactWithdrawnReferences,
  permit: (field, {now}) => {
    const policy = reviewedPolicies.get(field.sourceId);
    if (!policy || field.policyVersion !== policy.version) return {allowed: false};
    return admission(policy, {...field, dependencies: []}, {
      owner: verifiedAccount, action, audience, market, consent, now
    });
  }
});
```

Clearing dependency flags in this adapter isolates the existing rights check;
the evaluator resolves all actual references instead of trusting saved flags.
The adapter is illustrative, not deployed or an entitlement implementation.
Load only authorized account assertions and explicitly public inputs. Private
dependencies across accounts, or from public outputs into private inputs, fail.
Permitted public inputs can support a private assertion, subject to `permit`.

Explicit withdrawal/quarantine, retention expiry or malformed retention, current
policy denial, missing exact dependencies, and cycles withhold dependents.
Unrelated fields, source identities and versions remain independent. Values,
quantities, uncertainty, evidence class, and consent are not rewritten or inferred.
Bounds: 256 assertions, 256 withdrawal references, 2048 edges, 256 characters per
identity component. Invalid structure throws: the caller must treat that as
withholding the attempted output, not fall back to a cached grant.

Server owners must choose the storage representation and authoritative revisions,
build a complete bounded snapshot, re-evaluate reads/exports/derived uses and
withdrawals, and apply decisions atomically with concurrent rights/source changes.
For larger graphs, withhold or obtain an owner-designed partition contract; do
not truncate dependencies. The module performs no persistence, transport, cache
deletion, source collection, indexing, publication, or policy update. No caller
currently imports it. Existing app/UI/auth/schema/source data are unchanged.
Permission to reuse never establishes medical safety, allergy suitability,
nutrition equivalence, expiry, ownership, purchase authority, or verification.
