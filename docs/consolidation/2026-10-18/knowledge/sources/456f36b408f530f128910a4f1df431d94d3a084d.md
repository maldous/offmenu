## Independent integration contract

`public/intake-entry-model.js` exports two pure functions:

- `createIntakeEntry(input, {accountId, clock})` snapshots bounded JSON input and
  stamps it using a caller-injected ISO timestamp clock. Caller supplies stable
  entry ID, account/member scope, calendar date, kind (`meal`, `water`, `snack`,
  `restaurant`, `substitution`), state (`planned`, `consumed`, `unknown-consumed`),
  physical quantity (`g`, `ml`, `count`, `portion`), food identity and explicit
  recording consent. An unknown consumed quantity must be `null`; explicit zero
  consumption is valid. Planned quantities never become observed consumption.
- `partitionIntakeEntries(entries, {accountId, memberId?})` returns detached
  `planned`, `consumed`, and `unknownConsumed` buckets. Exact account/member
  selection, withdrawn recording consent and duplicate-ID rejection apply.
  Omitting member selection includes both household and member entries once.

Food references require `id`, `label`, and
`source: {id, recordId, rights}`. Rights are recorded assertions (including explicit
`unknown`), not source-use permission. Substitutions require both `planned` and
`actual` food references; actual identity must match the entry food. Additional
bounded JSON provenance, uncertainty and consent fields survive unchanged.
Consent requires `{id, purpose: 'intake-recording', granted: boolean}`; a recorded
assertion cannot authenticate an account or prove consent by itself.

Example caller adoption (illustrative, not wired into the application):

```js
import {createIntakeEntry, partitionIntakeEntries} from './intake-entry-model.js';
const entry = createIntakeEntry({
  id: 'stable-local-event-id', accountId: authenticatedAccount.id, memberId: '',
  date: '2026-10-14', kind: 'water', state: 'unknown-consumed',
  quantity: {value: null, unit: 'ml'},
  food: {id: 'self-report-water', label: 'Water',
    source: {id: 'self-report', recordId: 'stable-local-event-id', rights: 'unknown'}},
  consent: verifiedRecordingConsent,
}, {accountId: authenticatedAccount.id, clock: injectedISOClock});
const buckets = partitionIntakeEntries([entry], {accountId: authenticatedAccount.id});
// Owner-approved private storage/transport may persist the typed entry next.
```
