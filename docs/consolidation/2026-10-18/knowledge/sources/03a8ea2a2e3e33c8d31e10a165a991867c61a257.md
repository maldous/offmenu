# Worker 05 development composition interface

This interface is ready for owner review, not combined application acceptance. Default startup keeps deny-all outbound and the Worker 05 birth-verified lifecycle. Mock startup is opt-in through an absolute `OFFMENU_DEV_COMPOSITION` JSON path plus its exact `OFFMENU_DEV_COMPOSITION_SHA256`. Supplying only one value, missing files, stale qualifications, unqualified ownership or mismatched hashes stops startup before port probing, run reservation or D1 writes. No source branches are merged and no artifacts are copied.

Morgan must approve the application composition, and the operator supplies the reviewed descriptor pin. A hash and approval-reference string identify the evidence; they cannot independently prove a human approval. The caller must obtain that approval through Gateway before supplying the descriptor. Do not fabricate qualified receipts to unblock execution.
