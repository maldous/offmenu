# Local JSON basket report

Run with Node.js 22 or newer. No package install, credentials or service is needed:

```sh
node scripts/owner20-basket-report.mjs examples/owner20-basket-report.synthetic.json
cat examples/owner20-basket-report.synthetic.json | node scripts/owner20-basket-report.mjs -
node --test tests-web/owner20-basket-report.test.mjs
```

The example contains invented quantities and nutrient observations explicitly marked
synthetic. It represents no country, product or observed diet. Its fibre difference
is 5 g per 1,000 kcal, calculated by the existing engine; no overall ranking follows.

Input is one JSON object with `metrics` (1–100 unique `metric_id`/`unit` definitions)
and `baskets` (one or two baskets). Basket lines and nutrient records use the existing
`public/basket-model.js` contract. Nutrients require source ID, definition, matching
preparation state, unit, and per-100-g basis. Amounts without usable mass/density or
portion evidence remain unknown under that engine. JSON input is limited to 2 MiB.

The JSON report contains the unmodified `calculateBasket` results, including
`missing` line IDs, `definitions`, `status`, coverage, `knownSubtotal` and nullable
totals/denominators. A known subtotal of zero with a null total remains incomplete
evidence. For two baskets, `comparisons` contains the exact `compareBaskets` result
for every supplied metric: comparable difference, incomparable reason, or withheld
reason. For one basket it is empty. Engine `rankEligible` is passed through as an
engine diagnostic, not a ranking or new admission decision.

The wrapper adds no nutrition arithmetic, density, source joining, lookup or meaning
inference. It captures no health profile and writes no persistent data. The report
includes the input nutrient lineage, so redirect stdout only to a suitable local
destination. Semantic source qualification remains the caller's responsibility.

Success writes one JSON document to stdout with exit 0. Invalid input or an engine
failure writes a JSON error to stderr with exit 2 and no report on stdout. Non-finite
engine output is rejected rather than serialized as a misleading null. No raw
stack is emitted. `--help` prints usage.

Portable runtime closure: this script, the example, `package.json` (ES module
setting), `public/basket-model.js`, `public/i18n.js`,
`public/locale-negotiation.js` and `public/locales/ar.js`. The test is optional for
execution and uses only Node builtins plus this closure. Copy paths unchanged into
an isolated directory; Node resolves local imports without installing the package's
listed app dependencies. The review packet records exact hashes and an actual
isolated run outside Git with no node_modules.
