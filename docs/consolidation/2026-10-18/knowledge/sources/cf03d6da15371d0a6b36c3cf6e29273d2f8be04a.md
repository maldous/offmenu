## Concrete gap and scope

[Existing extraction](../scripts/i18n-catalogue.mjs) already inventories missing
Arabic candidates and checks placeholders/duplicate keys/plural fallback. Its
`--complete-ar` gate already rejects missing messages. This work reuses the
existing inventory and catalogue rather than implementing another extractor.
The coverage report has presence booleans, but no per-message UI language review
receipts tied to current source and translation digests. Catalogue presence
therefore cannot prove language review. Existing common-corpus review applies to
separate source/digest/citation records and is not UI catalogue approval.

Bounded existing-source example: `public/app.js` supplies
`\nAlways check the package for allergens.`. Existing `hasTranslation(key,'ar')`
returns false and `t(key,{},'ar')` preserves the English source text. Conversely,
`Breakfast` is translated, but no per-message reviewer receipt is supplied.
The synthetic negative has a fully present pack and still reports review
evidence incomplete; valid synthetic receipts only qualify the synthetic input.

## Deliverable and checks

[Audit](../tests-uiux/locale-coverage.mjs) exports pure `auditLocale(inventory,
catalogue, reviews)` plus `digest(value)`. It rejects inventory presence/count
drift, empty/malformed translations, placeholder mismatch, incomplete Arabic
plural forms, duplicate/stale/unattributed receipts and orphan receipts. It does
not translate, change product state or infer safety or rights from missing data.
No clocks, storage, transport, providers or account data are needed. Inputs remain
unchanged. No Git-writing fixtures or child processes are used by the audit.

[Manifest](locale-completion-manifest.json) lists every missing candidate and
every present candidate with unknown review status, with exact-byte SHA-256 pins
for the inventory, catalogue and referenced sources. SHA-256 receipt digests use
UTF-8 `JSON.stringify(value)`; plural object property order is significant.
No review receipts were supplied or fabricated. Result: 2,074 candidates;
376 present; 1,698 missing; 0 structurally invalid; 376 review-unknown;
0 reviewed; review evidence incomplete.

Focused commands (two Node invocations only):

```sh
node tests-uiux/locale-coverage.mjs --write --self-test
node tests-uiux/locale-coverage.mjs --check --self-test
```

Both exercise 11 bounded synthetic assertions plus five existing-source/runtime
assertions. `--check` compares the reproducible manifest byte-for-byte, including
source pins. `--write` changes only the reserved manifest. Neither calls another
process or writes Git state. Shared common directory, main ref and primary index
are checked before/after; only Worker 32's index/ref receive this deliverable.
