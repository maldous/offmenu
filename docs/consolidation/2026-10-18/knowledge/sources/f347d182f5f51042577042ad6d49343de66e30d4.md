## F1: evidence expiry during asynchronous evaluation is not rechecked

Module captures evaluationNow after authorizeEvidence, then awaits each
evaluateScoped call and returns its result without a final clock check.
Reproduction using the author's base fixture and real retained evaluator:

```js

const result = await consumer(base, {
  clock: () => lateClock,
  evaluateScoped: async input => {
    const result = packageRestrictionEvidence(input);
    lateClock = Date.parse(base.evidence[0].freshUntil);
    return result;
  }
})(selection);
```

Observed status pass returned at 2026-11-01T00:00:00.000Z, the exclusive expiry
boundary. Evaluation began at 2026-10-15T03:00:00Z. Author tests cover expiry
during authorizeEvidence but not during evaluateScoped or between preferences.
Correction: withhold current positive results if their scoped dates have expired
by completion, or expose explicit as-of/valid-until semantics and require a
trusted consumption-time requalification contract. Do not label stale results
current. Add an asynchronous evaluator expiry regression.
