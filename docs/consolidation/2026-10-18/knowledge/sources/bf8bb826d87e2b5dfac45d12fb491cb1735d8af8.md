# Fineli local reader contract

This offline CLI/library reads an explicitly supplied absolute manifest path and required expected SHA-256. It verifies the manifest's exact bytes, source/release, compressed profile file and reviewed citation dictionary by byte count/hash. No default dataset, Git lookup, acquisition, persistent index, canonical writer or app wiring. Missing/mismatched inputs fail with ReaderError (CLI JSON error on stderr, exit2). Argparse usage errors also exit2. Found/not-found results use exit0 and explicit status; not-found never means safe or absent nutrient.

Library: load `scripts/fineli-reader-owner49/reader.py` with importlib; construct `FineliReader(manifest, expected_sha256)`. `food(original_id, component_codes=())` matches provenance.recordId exactly and optionally filters by exact sourceComponent codes, preserving the existing fields of retained observations. `component(source_code)` returns the reviewed source terminology/unit/basis/citations by exact component code. `search(text, language=None, limit=10)` matches only literal case-sensitive substrings of publisher food labels in data.names. Languages fi/sv/en; limit1..100. No fuzzy lookup, generated aliases, casefold join or equivalence. Component labels cannot serve as food aliases. A limit truncates results without asserting complete matches.

Results include source/release, explicit input pin, rights and holds. Food output retains reported numerical values/nulls, original IDs/names, units, 100g source-described basis, method/acquisition qualifiers and provenance. Publisher component/unit labels and zeroMeaning holds are supplied by the exact reviewed attachment, not generated translations. Source input stays external, immutable and unmodified. Component dictionaries are small in-memory maps; a food/search operation binds a verified compressed byte snapshot (~20MB for this packet) and decompresses sequentially until the request is satisfied. No source payloads are checked into Git. Synthetic fixtures are explicitly invented and have no source rights/acceptance significance.
