# Closed whole-family phase projection

`corpus/whole_family_phase_adapter.py` builds one versioned foundation policy
from the exact accepted R8 input, its registry, independent rule receipt and
separate conditional type receipt. It projects already-closed hook results;
it never evaluates the classifier or opens a corpus/index/service.

The current accepted input selects three new whole-family rules. Every result
requires the qualified gate to have passed without suppression, the identical
whole-context resolution, exact accepted rule/target/source scope, a separately
reviewed type link and source-bound field commitments. The caller supplies the
native identity and exact dual-view barcode evidence after independent retained
source readback. An index barcode posting alone cannot supply those arrays.

All 24 controlled parameter axes are unknown in this new rule-specific policy.
Existing context variant assertions and source attributes are retained as
separate output fields, with the original hook's canonical hash. The producer
must retain existing qualified R2/R7/USDA rows and their policy/review stamps
when composing a versioned cut; this adapter does not replace those rows.

Returned candidates still require independent implementation review and actual
source/identity/operation qualification. The class does not admit foundation,
normalization, Gold, publication, runtime activation or physical equivalence.
Actual use must measure the eligible GTIN subset and overlap with the current
cut. Non-GTIN classifications remain retained source results.

Run focused generated-only tests with:

```
python3 -m unittest discover -s tests-web -p whole_family_phase_adapter_test.py -v
```

The tests also pass generated candidates to the unchanged JavaScript v2
assessor. No operational source records, accounts or network are needed.
