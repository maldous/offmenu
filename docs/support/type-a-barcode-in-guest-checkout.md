# Type a barcode when the camera is blocked

You do not need to allow camera access to type a barcode.

1. Open **Scan groceries**, then **Open my checkout**. Leave the camera off.
2. Open **Type or use a USB / Bluetooth scanner**. In **Barcode**, type the
   printed code, including any leading zeros.
3. Follow the button shown on your screen:

   - **Find** checks for 4–32 digits. If the value does not pass, focus
     returns to **Barcode** without clearing what you typed or adding an
     item. Correct it and choose **Find** again.
   - **Inspect retained barcode** opens a separate scanner with the code
     you entered. If you prefer to enter it there, choose **Open retained
     scanner** and then **Type code**. See the
     [retained scanner guide](../scanner-user-guide.md#type-the-printed-code-or-use-a-photo)
     for its own entry controls and format hints.

An unknown item in the checkout draft is not a verified product match. Check
the package and review the draft before confirming pantry changes. **Void
last item** removes only the most recent item from the draft.
