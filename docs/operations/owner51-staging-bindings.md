## Offline commands

Run from the repository root:

```sh
python3 -m offmenu.refresh.portfolio_owner51 describe
python3 -m offmenu.refresh.portfolio_owner51 fixture --bundle tests/fixtures/owner51 --as-of 2026-10-18T00:00:00Z
python3 -m unittest discover -s tests -p test_portfolio_owner51.py
```

The fixture command returns the manifest and shared qualification receipt. Optional `--output /private/existing-parent/fixture.jsonl` writes only qualified authored fixture JSONL. An identical existing file is a no-op; different existing bytes are a conflict. No parent directories are created or existing outputs overwritten. A fixed as-of timestamp makes replay diagnostics reproducible. A current date outside the fixture reuse window correctly holds; the demonstration timestamp is historical and does not renew real source freshness.

No network or AI call is made. The code has no production-input flag, force switch, automatic refresh, source substitution or public output route. Shared serialization preserves source order, literal strings and nulls. Shared field-origin validation covers each datum; the fixture-specific semantic validator additionally checks exact values, selectors and identities against code-owned authored expectations. Shared qualification checks input inventory/pins, candidate bytes, count/IDs, schema and provenance. The qualifier is called with `fixture=True`; the separate acceptance API is never called.

## Lifecycle and diagnostics

The minimum reuse window is 30 days from **original acquisition**. Validation time is separate and cannot extend it. Reuse-window metadata never grants source-use permission. Held or stale input returns before bundle access; at exactly 30 days the result requires separately authorized revalidation and no network attempt occurs. Real SE acquisition is recorded as `2026-10-14T22:13:35.858382+00:00`; its later render validation is a separate timestamp, not a new fetch. Missing acquisition times for other portfolio inputs remain unavailable.

Diagnostics cover missing, mismatched/malformed/oversized, symlinked, extra-inventory, stale, future-clock, provenance/value, count/identity and output-conflict failures. Malformed or drifted fixture bytes fail the trusted hash gate before parsing. Independent fixture diagnostics retain valid peers when another input fails. No records are silently dropped or admitted.
