## Reuse, animation and performance

Repository owns geometry.js, build-art.mjs and glTF masters; regenerate at build/authoring time, never on each product view. Ordinary ingredient UI consumes version-pinned cached2D SVG; preserve aspect ratio at64/128/256/512CSS pixels. glTF is an interchange export; lightweight landing uses the exact same procedural vertices. Local modules lazy-load only for desktop width>=900 and normal motion. Narrow/reduced-motion environments get geometry-derived static SVG. No new library, service, generation call, credential or backend call.

The experimental native renderer now caps DPR1 and15fps; pauses with story/offscreen/hidden state; per-chapter geometry/GPU buffers cached for one mounted scene, freed on disposal. WebGL failure/context loss retains static fallback. Rotation is true camera projection through XYZ meshes. No physical old-tablet, GPU, battery or wire-byte claims. SVG triangle exports are provisional and can be simplified offline for final production assets.

Character future anchors: ground/root, hip, neck/head, left/right shoulder/elbow/wrist, palm grip, phone screen and barcode aim. Door hinge at right vertical edge; drawer on front axis; microwave/oven door pivot specified before rigging. Appliances are planned unless registry lists an actual proof. Current adult/phone transforms are composition, not a skeletal animation rig; current motion is camera orbit and chapter geometry progression.
