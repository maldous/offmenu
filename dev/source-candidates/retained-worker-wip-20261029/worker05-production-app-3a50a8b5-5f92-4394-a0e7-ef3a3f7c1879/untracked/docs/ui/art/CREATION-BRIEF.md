# Reusable original asset creation brief

Copy for each missing asset. Do not mark planned output built.

- AssetID/version and status; owner/reviewer; category and exact selected variant/reference hash.
- Evidence-backed identity; physical form; packaging; explicitly unknown properties. Reviewed alias IDs only, with review receipt. Never derive appearance from nutrients.
- Silhouette: front/side/back requirements and recognisable feature; no reference labels/borders. Palette/material/outline/light/camera from STYLE-GUIDE.md.
- Geometry: metres/Y-up/ground pivot; measured illustrative bounds; mesh-part names; topology/normals; no unnecessary hidden detail. Character proportions and joints or appliance hinge/drawer anchors. Explain purposeful openings and simplified parts.
- Deliver editable original source + glTF2 embedded master + cached transparent2D SVG/render + static fallback + thumbnail, hashes and provenance/license. No generation on product view.
- Budget target: ingredient<=2000triangles, hero scene<=10000triangles, no external texture/network dependency; measure file sizes, fit and actual renderer cost, do not substitute estimates.
- Acceptance: reference review; original-work declaration; finite/index/normal and dimensional checks; three views; controls/motion/fallback; alias review; asset-family coherence. Record pending vs approved separately.
