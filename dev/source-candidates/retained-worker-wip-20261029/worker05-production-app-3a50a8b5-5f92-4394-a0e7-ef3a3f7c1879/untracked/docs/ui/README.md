# OffMenu presentation system

The repository is the source of truth. Start at [design-system/README.md](design-system/README.md) for the shared vanilla design system, native component APIs, theme contract and working playground catalog. Do not introduce a second framework or store merely to use UI components.

The existing application remains intact. P41 playground routes are a reversible, isolated presentation surface; they do not qualify real authentication, cloud persistence, source rights, nutrition completeness or device capability.
