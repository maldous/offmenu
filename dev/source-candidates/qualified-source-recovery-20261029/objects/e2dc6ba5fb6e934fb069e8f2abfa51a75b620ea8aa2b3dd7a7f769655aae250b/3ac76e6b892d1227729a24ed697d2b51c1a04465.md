source and implementation pins independently. Candidate/source JSON digests are
explicitly distinguished from original publisher record-byte digests. Results
always set `packageAdmitted:false`, `automaticPlanningEligible:false` and
`conversionEligible:false`. Schema-valid packets do not establish semantic,
rights, release or whole-package admission.
