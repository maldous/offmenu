## Concrete findings

- Current `public/unified-data.js:normalizeOFF` omits raw `rev` and `last_modified_t` in all 1,000 records. `scripts/collect-jsonl.mjs` subsequently adds export `releaseId`, `sourceRow`, and archive hash, preserving archive custody but not per-record revisions. `scripts/align-bulk-food-common.py:source_citation` uses releaseId for revisionId: an export release is not the source product revision.
- `serving_size` is omitted in 848 records, `serving_quantity` in 842, and `serving_quantity_unit` in 787. Package amount/unit/label remain independent. Raw serving-suffixed nutriments survive in rawNutriments; without serving metadata they do not establish a serving/package conversion.
- 568 records get a gram basis without explicit `nutrition_data_per=100g`: 410 specify `serving`, 158 lack a declared input basis. This flags unresolved denominator context; it does not establish that computed `_100g` numbers are wrong. Do not derive density, substitute package quantity, or rescale serving values automatically. Prepared-basis metadata exists in 779 and is omitted; metadata alone does not establish actual prepared nutrient availability.
- Nutriment trees survive unchanged in this sample. Allergen, trace and origin tag arrays normally survive; two allergen fields and one origin field undergo null-to-empty coercion, losing missingness. Raw declaration strings and their source/language context are omitted. User-string loss counts include language-only markers such as `(en) `, which are not interpreted as declared allergens/traces.
- 997 barcode strings pass GTIN syntax/check-digit checks, three fail. These checks establish neither registered identity, ownership, physical producer, dietary suitability nor record admission. Leading zeros remain intact.

The common graph schema already supports source-scoped resources, citations, typed source fields and unknown values. Its sourceFields assertion preserves the normalized tree, but cannot restore fields lost upstream. No shared normalizer, schema or importer was changed.
