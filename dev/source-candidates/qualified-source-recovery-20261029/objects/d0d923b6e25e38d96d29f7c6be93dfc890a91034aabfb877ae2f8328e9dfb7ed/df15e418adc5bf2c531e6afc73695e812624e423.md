# Private waste-observation preservation

This composes on Owner02 receipt-identity pin `8ba00e638a1855c8b738298b31d7e1d0efa40d8b`. Owner02's app producer and receipt-ID checks are unchanged. `validateState` now retains the already-required private `profile.wasteObservations` snapshot through a separate bounded validator. No persistence service, schema, D1 adapter, endpoint or observation producer is added.

Required fields are `id`, `accountId`, `receiptId`, `sourceId`, canonical UTC `observedAt`, `quantity`, `unit`, and `provenance.sourceRef/method`; existing optional `reason` is retained when present. IDs are opaque nonempty strings bounded to 200 characters, matching receipt-ID bounds. Source references are bounded to 1000 characters; methods and units to 100; reasons to 200. No strings are trimmed, sliced or relabelled. Unknown quantity/unit may be explicit null. Finite nonnegative quantity requires a nonempty unit and `measured` provenance. Explicit zero is preserved; the existing positive-only analysis consumer still withholds its aggregation. Missing history remains absent; explicit empty remains empty. Present malformed history, unsupported fields, duplicate IDs or overlapping receipt/source pairs are rejected. No cost, season, pack or generated authority fields are admitted.

This validator validates stored shape, not truth, consent or account ownership. It does not manufacture receipt IDs, infer links or join receipts. Existing `wasteInsight` must still require authoritative account/session/consent/read context and one exact confirmed receipt/item binding, matching unit and quantity within the confirmed discard. Legacy or unmatched receipts remain unqualified. Private metadata is never added to public data-record projections. No widening of observation read authority is implied.

The standalone D1 protocol's canonical-state/digest boundary remains unchanged: a valid canonical snapshot now preserves these fields; unsupported fields still cannot silently disappear into an admitted command. The initial contract's incorrect claim that this preservation already existed remains corrected by the retained amendment; this is the separately selected implementation, not retroactive evidence.

Independent full `302c9bfc` producer/confirmation/cloud regression after composition is reserved for Owner03. Local focused tests do not certify caller wiring, real account authority, cloud persistence or production adoption.
