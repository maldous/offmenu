### Mandatory trusted store interface

`store.read({selectionId, context, signal})` supplies the authoritative selection
snapshot. `store.readIfCurrent(expected, consume)` must conditionally read both
that selection and **independently authoritative** source/policy rows. It must not
replay cached node status/rights as authority. It invokes the synchronous consumer
exactly once with `{selection, sources}` iff all expected selection/source bytes,
revisions/epochs and account context remain current, returning
`{matched:true, value}`; otherwise it refuses. It must not retry a side-effecting
consumer or accept a client-provided snapshot in place of current store rows.

This module checks the returned selection and source rows against exact captured
bytes, then checks current status/rights/retention using the trusted nondecreasing
clock inside the condition callback and again after asynchronous acknowledgement.
Store implementations must provide the actual conditional/atomic source-row read
semantics; this repository change supplies **no** database adapter, registry,
schema migration or durable producer selection. Tests use an independent in-memory
selection and source registry to prove the consumer boundary, not D1 parity.

Rights/epochs are gated before reservation, after reservation/before transport and
after transport/projection digest/before release. Only `reserve().dispatch===true`
permits dispatch; budget is not a rights grant. This does not implement durable
idempotency, charging, refund, lease or per-provider quota policy: Owner 30 supplies
those under its own reviewed contract. Abort/context changes reject stale results.

The selected transport verifies exact manifest and gzip bytes and feeds its
unchanged common graph reader. This adapter additionally matches every selected
receipt row (dense exact order/key/hash/bytes/indexes), the authoritative visible
resource/assertion/relation/citation graph digest, and every citation's source ID,
document revision, original-content hash, URL, licence and attribution. Source text,
IRIs, expressions, unknowns and locale projection are not rewritten. Compressed
packet pins bind translation bytes; the projection digest is deliberately not a
new full-packet or publisher-byte hash. An original-content hash alone does not
prove independent publisher retrieval.

Output provenance contains producer/selection/source/policy revisions for review;
it is not a grant or a replacement for Owner 29's source guards. No cached-node
guard override, cache write, public promotion or long-lived authorization is
provided. Subsequent cached reads/exports require their owner's current guarded
store path; an earlier returned reader is not ongoing revocation enforcement.
