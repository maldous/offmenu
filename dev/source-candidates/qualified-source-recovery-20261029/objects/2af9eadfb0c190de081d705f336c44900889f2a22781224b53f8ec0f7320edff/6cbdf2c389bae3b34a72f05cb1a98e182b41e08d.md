## Real consumer contract

`public/reference-view-owner22.mjs` consumes an injected reviewed referenceViews
implementation. It emits seven rows per metric, including value, unit, explicit
basis/denominator, view/numerator status, estimate flag, known subtotal, mass and
energy coverage, named profile and withheld reason. Declared serving provenance
is explicitly labelled unverified in the displayed basis. No private storage, clock, provider or account lookup occurs.
It checks calculation/request identity, version, state, population, track, purpose,
period, person-days, line IDs, source nutrients, original quantity and composition
version. It also recomputes all arithmetic using the existing basket/1.1 calculator
and the response metric dictionary, comparing every calculator-owned output. This
binds edible mass, conversions, line preparation and food-group inputs. Additional
server metadata survives. This is consistency checking, not evidence verification.
The original request is retained in a detached requestSnapshot/referenceRequest,
including source units, provenance, rights, consent and uncertainty supplied there.

`readDeclaredReferenceBasis` explicitly validates optional basket.serving and
basket.referenceProfile JSON envelopes. Serving requires source/recipe IDs and
versions, basket/version/state binding, and exactly one positive defensible fraction
or measured mass. A valid user declaration is labelled as unverified recipe provenance.
It does not establish observed intake, dietary suitability or nutrition equivalence.

Client-declared reference names/targets, including null unknown targets, are preserved
in suppliedBasis.requestedReferenceProfile and shown as unqualified declarations.
They NEVER authorize reference percentages or source admission. Default consumer
integration withholds percentages until an owner-controlled resolver supplies the
selected independently qualified analytical profile. Unknown != zero. Even a
syntactically well-formed profile cannot self-assert qualification with an input flag.
The independent helper review is distinct from qualification of real target data.
No real reference target dataset is currently selected by this candidate.

An owner-qualified resolver may return the helper's serving/referenceProfile shape.
Named system/id/version/lifeStage, compatible definition/unit and positive reference
amount are still required by the helper. This consumer additionally withholds
complete-but-conflicting reference targets, preserving original supplied evidence.
No overall health ranking or cross-profile basket comparison is offered.
All source/quantity/uncertainty metadata supplied to the calculation is retained
in its presentation snapshot, without evaluating or granting permissions.
