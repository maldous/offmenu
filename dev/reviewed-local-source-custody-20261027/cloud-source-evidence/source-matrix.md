## Existing field vocabulary to use—not replace

The existing [parsed dictionary](https://github.com/maldous/offmenu/blob/dc39d0d7f29f0b0650be374f0e7e2111ec45c4b7/corpus/parsed-data-dictionary.json), [field mappings](https://github.com/maldous/offmenu/blob/dc39d0d7f29f0b0650be374f0e7e2111ec45c4b7/corpus/source-field-mappings.json) and [common field map](https://github.com/maldous/offmenu/blob/dc39d0d7f29f0b0650be374f0e7e2111ec45c4b7/corpus/common-source-mappings.json) already provide these destinations:

| Source fields | Existing destination / identity | Preserve rather than infer |
|---|---|---|
| Source ID/release/record/URL, raw and extraction hashes, page/line/pointer/span | Citation, SourceDataset, SourceRecord; `source.*` | Release versus acquisition time; original versus extracted bytes; source ordinal versus publisher ID |
| Product codes / identifiers | Typed source identifier assertions, lexical identifier pool | Leading zeros, namespace, repeated and conflicting occurrences; valid checksum is not authenticity |
| Names / foodName / localized names | Resource names / CulturalRepresentation | Locale and original hash; name similarity is not food, product or recipe identity |
| Original ingredient expression / preparation / substitutions | IngredientMention; `ingredientLines[].originalExpression`, `sourceNameText`, descriptors and source substitution text | Contains versus is-ingredient versus usable-as; explicit alternatives, optionality and raw/cooked state |
| Quantity numeric/unit lexemes, basis, qualifiers | Quantity / MetricBasisDefinition | Blank/null/trace/ND/less-than/zero; source measures, ranges and dimensional basis |
| Nutrition label/value/unit/basis/method | FoodCompositionObservation → source NutrientDefinition | Method-specific carbohydrate/fibre/energy; no English-label equality, averaging or silent conversion |
| Recipe title/yield/ordered steps/notes | RecipeVariant, RecipeStep, IngredientScalingRule | Source order, exact text, yield unknowns; translation separate from parsing |
| Menu item name/description/category/price/venue | MenuItem and source-linked PriceObservation / Site | Menu description is not ingredient proof; currency symbol and code ambiguity; venue not verified legal owner |
| Price/market/date/currency | Dated PriceObservation | CPI/estimated commodity series/household basket cost are not retail offers or live stock |
| Organizations/roles/relationships/sites | Organization/Producer/Supplier/Retailer/OwnershipAssertion | Brand owner, manufacturer, packer, distributor and operator may differ; date/scope remain attached |
| Recalls/qualification/labels | Source notice/assertion with issuer, product/lot, market and dates | A source claim is not verified safety or diet eligibility |
| Other source fields | `UnmappedSourceFact` / existing typed structure assertions | Do not drop unfamiliar columns or manufacture a semantic equivalent |
